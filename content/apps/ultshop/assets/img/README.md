# UltShop Images

This directory contains image assets for UltShop:

- Product images
- Icons
- Logos
- Banners

## Usage

Images should be optimized for web and referenced from the product catalog in `config/products.js`.

## Format Guidelines

- Product images: 400x240px (recommended)
- Icons: 64x64px
- Use web-optimized formats (WebP, PNG, JPG)
